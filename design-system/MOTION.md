# 设计系统：动效规范

> 派生自 `MASTER.md`，是动效维度的**判断依据**。MASTER 只给了 3 个 duration token 与 2 个 easing token，未给「哪个元素用哪个」的映射——本表补齐该映射，避免实现时各自解读。
> 配套：token 值见 `tokens.css`，视觉基线见 `MASTER.md`，页面原型见 `preview.html`。

## 1 · 时长与缓动

| Token | 值 | 语义 |
|---|---|---|
| `--dur-fast` | 150ms | 即时反馈 |
| `--dur-base` | 200ms | 结构变化 |
| `--dur-slow` | 280ms | 场景级转换 |
| `--ease-out` | `cubic-bezier(.22,.61,.36,1)` | 通用 |
| `--ease-spring` | `cubic-bezier(.34,1.3,.64,1)` | 弹入（含轻微过冲） |

`--ease-spring` 的控制点 `1.3` 会产生约 3% 的过冲——只允许用于「从无到有」的入场，不允许用于位置移动（过冲会让文字错位一瞬）。

## 2 · 元素 → 动效映射

| 元素 / 交互 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| hover / 状态色变化 | `--dur-fast` | `--ease-out` | 不移动位置，只改色 |
| focus 环出现 | `--dur-fast` | `--ease-out` | 键盘用户须立即看到 |
| 抽屉滑入 / 滑出 | `--dur-base` | `--ease-out` | 从右滑入，位移距离 = 自身宽度 |
| 弹窗（Modal）开 / 关 | `--dur-base` | `--ease-spring` | 缩放 `.96 → 1` + 透明度 `0 → 1` |
| Toast 进出 | `--dur-base` | `--ease-out` | 从右下角上移 8px + 淡入 |
| 侧栏展开 / 折叠 | `--dur-base` | `--ease-out` | 宽度 `240 ↔ 64`（MASTER §6） |
| 分段控件选中态 | `--dur-fast` | `--ease-out` | 高亮块位移 |
| 翻页动效 | `--dur-slow` | `--ease-spring` | 「翻页像纸」——见 §3 |
| 主题切换 | `--dur-slow` | `--ease-out` | 全站颜色过渡，「像晨昏交替」（MASTER §8） |
| LoadingSkeleton 微光 | 1400ms | `linear` | 唯一允许的循环动画（见 §3） |
| 阅读工具栏淡出 | `--dur-base` | `--ease-out` | 鼠标静止 2.5s 后（MASTER §5.3） |

## 3 · 例外与禁令

**允许循环动画的唯一例外**：`LoadingSkeleton` 的微光扫过。MASTER §4 禁止「无意义弹跳与循环动画」，而骨架屏的循环是**有意义**的——它传达「正在进行中」，停止循环会让用户以为界面卡死。该动画在 `prefers-reduced-motion` 下必须降级为静态灰块。

**禁止**：

- 禁止为位置移动使用 `--ease-spring`（过冲会让正文短暂错位）
- 禁止直接对 `width` / `height` / `top` / `left` 做过渡——改用 `transform`；确需过渡尺寸时（侧栏折叠）须接受重排代价并加 `will-change`
- 禁止动效时长超过 `--dur-slow`（骨架屏除外）——桌面应用不是展示页
- 禁止在主题切换时对**布局属性**做过渡（MASTER §4：只过渡颜色，不过渡布局），否则主题切换会触发重排

## 4 · 减少动效（`prefers-reduced-motion`）

系统开启时**全站降级为 0ms**（MASTER §4 / spec FR-032）：

| 交互 | 正常 | 减少动效 |
|---|---|---|
| 翻页 | 280ms 翻页动效 | 瞬时换页 |
| 滚动 | 平滑缓动 | 直接位移 |
| 抽屉 / 弹窗 / Toast | 200ms | 瞬时出现 |
| 骨架屏微光 | 1400ms 循环 | 静态灰块 |
| 主题切换 | 280ms 渐变 | 瞬时 |

**减少动效不得改变任何几何结果**：分页、滚动流布局、阅读位置在两种设置下必须完全一致（spec FR-032）。该开关是**渲染层**开关，不是排版层开关。
