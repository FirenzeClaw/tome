## User Scenarios & Testing *(mandatory)*

> 说明：S2 的交付物是**可被上层调用的排版与渲染层**（`tome-reader`）+ 上述能力的可验证入口。因此下文的"用户"包含两类：**最终读者**（完整体验依赖 S3 外壳，但其阅读质量由本规格决定）与**下游构建者**（S3 界面层开发者，依赖本规格的接口与不变量）。

### User Story 1 - 翻页阅读一本中文小说 (Priority: P1)

一位读者打开一本中文小说，看到已经排好版的书页：段落首行缩进、标点不孤悬于行首、两端对齐的汉字网格、章节标题居中且带分隔线。他用键盘或鼠标向后翻页，页面内容随之更新，页脚显示当前章节与页码。

**Why this priority**: 这是 S2 存在的理由，也是"引擎能力"变成"可读的页面"的唯一路径。只实现这一条，就已有可被 S3 接上的最小可用阅读页。

**Independent Test**: 给定一段含中英文混排、引号、破折号、省略号与书名号的固定文本与一组排版参数，在无图形环境下产出**分页结果**（每页的字符区间 + 行盒列表）；对同一输入执行两次得到逐字节相同的结果。像素级验证由离屏渲染产出图像并作快照比对。

**Acceptance Scenarios**:

1. **Given** 一篇含中英文混排与全角标点的正文，**When** 排版，**Then** 每一行的行长在版心宽度内浮动不超过 1 个标点挤压单位，且无任一行超出容器
2. **Given** 正文中出现 `“` `（` `《` 等开标点，**When** 排版，**Then** 该标点不出现在任何行的行末
3. **Given** 正文中出现 `，` `。` `？` `”` 等闭标点，**When** 排版，**Then** 该标点不出现在任何行的行首
4. **Given** 一段以缩进模式排版的正文，**When** 排版，**Then** 每个自然段首行缩进 2 个字身，且段间无额外间距；切换到间距模式后，每个自然段首行不缩进、段间有 0.4em 间距
5. **Given** 已分页的章节，**When** 读者请求下一页，**Then** 返回的页面内容与上一页不重叠、不丢字，字符区间连续
6. **Given** 最后一页，**When** 读者继续请求下一页，**Then** 展示章节末页而非空白页（空白页只出现在双页模式下为凑书页语义而留白的位置，见 FR-013）

### User Story 2 - 调整排版参数后不丢阅读位置 (Priority: P2)

读者把字号从 19px 调到 24px，或把窗口拉宽到双页模式，或从昼切到夜。页面重排后，他发现自己仍在原来那一句话上，而不是被丢到章节开头或随机位置。

**Why this priority**: 这是 S1 花力气建立的字符锚点契约（FR-027/SC-008）的**唯一消费方**。若 S2 不接住它，S1 的不变量就是白做的；而位置丢失是阅读类应用最直接的体验崩塌。

**Independent Test**: 取定一个字符锚点，对一组排版参数组合（字号 × 行高 × 版心宽 × 单双页 × 段缩进模式）逐一重排，断言重排后落在屏幕上的字符区间包含该锚点，且锚点值本身不变。

**Acceptance Scenarios**:

1. **Given** 读者正读到某页中段某字符，**When** 字号从 19px 变为 24px，**Then** 该字符仍在该页可见区域内
2. **Given** 单页模式下的阅读位置，**When** 窗口拉宽触发切换到双页，**Then** 该位置落在双页中的某一页上且为屏幕上可见的字符
3. **Given** 双页模式下的阅读位置，**When** 窗口收窄切回单页，**Then** 同上
4. **Given** 任意排版参数组合，**When** 保存并重新载入进度，**Then** 锚点值 `(chapter_index, char_offset)` 逐字段不变
5. **Given** 读者正停留在章节末尾的留白页（双页书页语义补足），**When** 切换参数，**Then** 不出现空白页被吞掉导致位置跳到下一章的情况

### User Story 3 - 渲染管线：字形缓存与稳定帧 (Priority: P3)

读者连续翻页，每一页在按下翻页键后立即可见，不出现空白帧、不出现字符闪动；翻页动效平滑，低端设备上降级为无动效而非掉帧。

**Why this priority**: 渲染管线是 P1 的物理载体。但它排在排版之后——没有正确的分页结果，渲染得再快也没有意义。

**Independent Test**: 预先分页若干章节并预热字形缓存，测量从"请求第 N 页"到"该页首个可呈现帧"的时间；对同一页渲染两次的图像作像素比对，断言除预热的字形缓存命中率变化外无差异（缺字回退字形导致的差异必须在首次预热后消失）。

**Acceptance Scenarios**:

1. **Given** 已预热的一章，**When** 请求已计算过的任一页，**Then** 该页在首帧即可见，不出现空页
2. **Given** 正文含生僻字或字体未覆盖字符，**When** 渲染该行，**Then** 以缺字回退字形呈现且该行其余字符位置与该字符用正常字形时一致（不整行跳动）
3. **Given** 系统启用减少动效，**When** 翻页，**Then** 无过渡动效直接换页，且换页耗时不超过有动效时的首帧时间
4. **Given** 阅读页与 S3 外壳 UI 同屏，**When** 阅读页滚动或翻页，**Then** 阅读页内容由本层的渲染管线独立产出，不经由外壳 UI 框架的文本栈

### User Story 4 - 阅读痕迹与词典在阅读层的呈现 (Priority: P4)

读者此前的书签、高亮与批注在阅读页上正确显示——改字号、切主题、换单双页后位置仍准确；选中一个词能触发查词并看到释义。

**Why this priority**: 这是"读得舒服"的跃迁，且它是 S1 的字符区间数据（FR-028/FR-015）在视觉上第一次落地。但建立在 P1-P3 之上。

**Independent Test**: 给定一组字母段落的字符区间痕迹与一组排版参数，断言每条痕迹渲染出的像素范围覆盖的字符**恰好等于**其字符区间（不多不少）。

**Acceptance Scenarios**:

1. **Given** 一条覆盖第 100–150 字符的高亮，**When** 以 19px 与 24px 分别渲染，**Then** 两次高亮所覆盖的字符集合完全相同
2. **Given** 一条跨越页边界的高亮区间，**When** 分成两页渲染，**Then** 两页各自只渲染落在本页的部分，且拼接后无缝隙无重叠
3. **Given** 读者拖选一段文字，**When** 释放鼠标，**Then** 得到的是字符区间而非像素范围，且该区间与 `resolve_anchor` 的口径一致
4. **Given** 读者选中一个词并触发查词，**When** 词同时在已加载的字典中，**Then** 阅读层请求词典结果并展示；失败时提示可操作原因而不静默

### User Story 5 - 无图形环境下的可验证性 (Priority: P5)

构建者（与 AI 代理）在没有窗口系统的机器上运行排版计算、分页、位置换算与像素快照比对的渲染部分，全部通过，不需要显示器。

**Why this priority**: 它决定 S2 能否进入 CI 与 TDD 循环。测试先行（宪法 III）要求每个任务有先失败的测试——若排版只能在有显示器的机器上验证，TDD 在 S2 就是空话。

**Independent Test**: 在无窗口系统的环境中执行一次完整排版 + 分页 + 位置换算 + 离屏渲染 + 快照比对，全部成功。

**Acceptance Scenarios**:

1. **Given** 无图形环境，**When** 执行排版与分页，**Then** 全部成功且不产生任何图形相关依赖错误
2. **Given** 无图形环境，**When** 执行离屏渲染与快照比对，**Then** 成功产出图像并给出可比较的差异
3. **Given** 无图形环境，**When** 调用排版层的**任何**公开能力，**Then** 引擎层（tome-core 及以下）与排版计算均不依赖窗口系统

### User Story 6 - 图文混排（插图页） (Priority: P6)

读者阅读带插图的书页：图片在正文的对应位置出现，占位高度与最终图片一致（加载时不引起正文跳动），图片不跨页断裂。

**Why this priority**: 内容完整性的一部分，但大量中文网络小说无图，且它的实现依赖 ContentProvider 的图片句柄（当前是契约缺口，见 Context A）。故排在最后。

**Independent Test**: 给定含图片位置的正文与一组已知尺寸的图片，断言分页结果中图片所在行的行盒高度等于按版心宽等比缩放后的图片高度，且图片未被页边界切开。

**Acceptance Scenarios**:

1. **Given** 一段正文中插入一张图片，**When** 分页，**Then** 图片整体落在单页内，不被页边界切开
2. **Given** 图片尚未获取到尺寸，**When** 分页，**Then** 按声明或回退尺寸占位，且在尺寸确定后重排不改变锚点
3. **Given** 图片位于章节首页，**When** 排版，**Then** 图片与其后的首段成组，不出现"图片在上一页末尾、说明文字在下一页开头"的孤立

### Edge Cases

- **章节正文为空或仅空白**：必须产出一页可呈现内容（含标题与明确提示），不得产出零页导致翻页越界
- **单章超长（数十万字）**：分页不得一次性把全章排版结果驻留内存后失败；必须能在限定内存内完成并支持只渲染当前页
- **单行超长（无空格的连续长串，如 URL 或整段无标点）**：必须在任意字符间断行（含西文按字符断），不得溢出容器或整行丢弃
- **正文含控制字符与零宽字符**：零宽字符不得影响断行与光标位置计算；控制字符按可见占位或丢弃，二者择一后保持稳定
- **正文含制表符与连续多个空格**：按预设语义渲染（制表符按固定字身宽展开），不得使行宽计算失准
- **正文含 emoji / 组合字符 / 变体选择符**：按字形簇（grapheme cluster）处理，不得在簇内断行或拆开高亮区间
- **正文含 RTL 文本**：按方向段（bidi）顺序排列；不得因混合方向使行盒错位
- **字体缺失或字体不含中文字形**：给出明确指引（001 §Assumptions「依赖系统字体并在缺失时给出明确指引」），降级为回退字形链，不得渲染为空
- **窗口极窄（小于一个字宽 × 2）**：必须给出明确的最小尺寸约束反馈，不得进入除零或负宽度计算
- **窗口极宽（超过 42em 单栏上限）**：单页模式不得把版心拉伸到超过 42em，超出部分留白
- **窗口在两次重排之间被频繁改变尺寸**：重排必须可合并/节流，不得因连续 resize 累积排队任务
- **排版参数被设为非法值**（字号 0、行高负、版心负宽）：必须在接受前校验并拒绝，回退到上一个有效值，不得产生无法渲染的状态
- **主题切换发生在分页时**：颜色变化不得触发重新分页（分页只依赖几何参数，不依赖颜色）
- **痕迹区间越过章节末尾**（锚点或高亮区间超出当前正文长度）：必须夹取到有效范围并在界面上可辨识，不得 panic
- **同一字符区间同时命中高亮与批注**：必须定义确定的叠加规则并稳定呈现
- **正文在两次打开之间发生变化**（书源更新章节内容）：锚点无法解析时按 S1 既有降级链处理，S2 只承接其结果
- **渲染目标不支持**（无可用图形后端 / GPU 驱动异常）：必须给出明确报告并保持排版计算可用，不得静默黑屏
- **离屏渲染在无图形环境下不可用**：像素快照测试必须降级跳过并明确报告跳过原因，不得伪装通过
- **阅读记录上报节流**：翻页过快或长时间停留不得产生高频写库
- **双页模式下窗口窄到放不下两栏（含中缝）**：立即回落到单页并保持锚点，不得渲染半栏

## Requirements *(mandatory)*

### Functional Requirements

#### 排版输入与文本模型

- **FR-001**: 系统 MUST 把章节正文字符串切分为**段落序列**，并 MUST NOT 依赖"首行缩进"来识别段落。段落边界 MUST 只由原文中的换行符确定（`\n`、`\r\n`、`\r` 视为同一类边界）；原文中的前导全角/半角空格与制表符 MUST NOT 作为段落标记，而 MUST 作为段内文本按空格类处理。[待裁决：见 OPEN-QUESTIONS #2]
- **FR-002**: 系统 MUST 在排版输入处定义一个**规范化的文本模型**（段落 → 字形簇 → 字形），且 MUST 使所有对外位置（字符偏移、区间、命中测试结果）以该模型的**字符下标**为单位——与 S1 的 `char_offset` 同口径（Unicode 标量值序列下标）。系统 MUST NOT 对外暴露字节偏移或 UTF-16 码元偏移。
- **FR-003**: 系统 MUST 以 001 契约（`ContentProvider::chapter_content`）作为正文的唯一来源，MUST NOT 自行读取缓存容器、发起网络请求或改写净化规则。正文的净化/替换/高亮求值顺序 MUST 沿用 001 §FR-014 的既有定义，本层 MUST NOT 重新施加。

#### 中文排版规则

- **FR-004**: 系统 MUST 以**行首禁则与行尾禁则**约束断行：不得把「行首禁则字符」（闭标点、句末标点、后引号、后括号、百分号与单位等）置于行首；不得把「行尾禁则字符」（开标点、前引号、前括号等）置于行末。规则集 MUST 以显式清单实现并逐项可测，清单内容见 FR-006。
- **FR-005**: 系统 MUST 实现**标点挤压（punctuation compression）**：当行末或行首出现可压缩标点时，系统 MUST 优先通过压缩该标点的字身而非增加/减少整行字符间距来满足行长与禁则。压缩 MUST 有下限（不得压到不可辨识），且 MUST NOT 改变字符的顺序或字符区间归属。
- **FR-006**: 中文排版规则集 MUST 是**显式、可枚举、可逐项测试**的清单，至少覆盖：开标点行尾禁则、闭标点行首禁则、连续标点压缩、行末标点悬挂或压缩的选择、行内中西文之间的最小间隙、行首行尾空白折叠、超长不可断行的强制断点策略。清单 MUST 附每项的判定例与反例。[待裁决：见 OPEN-QUESTIONS #1（规则优先序）与 #4（分歧裁决口径）]
- **FR-007**: 系统 MUST 实现**中西文混排间隙与断行**：中文与西文/数字交界处的处理规则 MUST 在 FR-006 清单内明确定义；西文单词 MUST 优先整词断行，整词放不下且单词长于整行时 MUST 退化为按字符断行（FR-Edge Cases）。
- **FR-008**: 系统 MUST 支持行内样式的最小集合（章节标题、强调/加粗、引用或居中行），且 MUST 支持"样式只影响外观与行盒属性，不影响字符区间归属"这一不变量——同一段文本在任何样式组合下的字符下标 MUST 一致。

#### 分页

- **FR-009**: 系统 MUST 把一章正文按给定几何参数计算为**页序列**，每页 MUST 以字符区间表达（`char_offset` 起点 + 长度），MUST NOT 以渲染坐标表达分页结果。
- **FR-010**: 系统 MUST 定义一个**显式、版本化的排版参数集**（几何子集与呈现子集分离），并 MUST 按 MASTER.md §5.1 支持这些可调项：阅读字号（14–30px，默认 19）、行高（1.4–2.2，默认 1.85）、段首缩进（默认 2em）、段间距（默认 0.4em，与段缩进二选一）、版心目标宽（默认 36em 上限、42em 绝对上限）、中缝宽（默认 64px）、单双页模式（自动/强制单页/强制双页）。该参数集 MUST 可序列化，并 MUST 作为 `Book.read_config` 的 schema（001 契约中该字段"内容由 S2 排版层解释"）。参数集的作用域（全局默认 / 每本覆盖）见 [待裁决：见 OPEN-QUESTIONS #12](./OPEN-QUESTIONS.md)；行高可调下限见 #19。
- **FR-011**: 系统 MUST 依据 **MASTER.md §5.2 的 em 制判据**决定单页或双页：可用宽度 ≥ 2 × 版心目标 + 中缝时启用双页。判据 MUST 以几何参数实时计算，MUST NOT 使用固定像素断点。字号变化时 MUST 重新计算该判据。（用户指令明确：单双页切换判据为 em 制非 px 断点。）"可用宽度"的定义（阅读区宽度 vs 窗口宽度）见 [待裁决：见 OPEN-QUESTIONS #22](./OPEN-QUESTIONS.md)。
- **FR-012**: 系统 MUST 实现单双页的手动覆盖（自动/强制单页/强制双页），手动选择在会话内 MUST 优先于自动判定；手动选择何时回落自动判定见 [待裁决：见 OPEN-QUESTIONS #14](./OPEN-QUESTIONS.md)。
- **FR-013**: 系统 MUST 在双页模式下遵循**书页语义**：左页为偶数页、右页为奇数页，且章节 MUST 从偶数页（左页）开始——若上一章结束于单页，系统 MUST 留白补足至偶数页再起新章。[待裁决：见 OPEN-QUESTIONS #5（单页模式下是否也遵循章起偶数页）与 #20（"长按可关"在桌面端改为何种开关形态）]
- **FR-014**: 系统 MUST 保证**分页与锚点解耦**：给定同一锚点 `(chapter_index, char_offset)` 与任意两组几何参数，系统 MUST 能分别定位到包含该字符的页与页内位置，且锚点值本身 MUST 不变。（对齐 001 §SC-008）
- **FR-015**: 系统 MUST 实现"段首缩进 / 段间间距"两种段落排布模式并按参数切换，二者 MUST 互斥（缩进模式无额外段距，间距模式无首行缩进）。
- **FR-016**: 系统 MUST 使分页结果的**页数只依赖几何参数**（版心、字号、行高、段缩进模式、中缝、单双页），MUST NOT 依赖颜色、主题、封面等呈现参数——主题切换 MUST NOT 触发重新分页。

#### 主题与排版参数

- **FR-017**: 系统 MUST 把排版几何参数与呈现参数（颜色、字体族、动效、噪声）分离为两类，前者决定分页，后者只决定绘制。
- **FR-018**: 系统 MUST 提供一个**单一的主题模块**，产出 `Theme` 结构体并给出昼/夜两个实例，承载 MASTER.md §2/§3/§4 的语义 token（色彩、间距、圆角、阴影、动效常量、字体三角色）；系统 MUST NOT 允许各绘制点散读常量。（用户指令明确：MASTER §10 的落地要求。）
- **FR-019**: 系统 MUST 支持昼（Parchment）与夜（Obsidian）两套主题的**完整语义色映射**；阅读区背景 MUST 使用主题的阅读层色（昼 `#F5EEDC` / 夜 `#000000`），MUST NOT 使用纯白作昼主题底，MUST NOT 用深灰替代夜主题真黑。正文色 MUST NOT 低于 MASTER.md §2.3 的 `--text-secondary`。
- **FR-020**: 系统 MUST 保证 MASTER.md §2.3 的无障碍判定在渲染层被**强制**（非可选皮肤）：正文与背景对比度达标、focus 环可见且不得被抹除、UI 触达目标不小于 32px。
- **FR-021**: 系统 MUST 支持**减少动效**（reduced motion）开关，并 MUST 在开启时把翻页与过渡动效时长降为 0（立即完成），同时 MUST NOT 因此改变分页结果或阅读位置。
- **FR-022**: 系统 MUST 把 001 契约中的 `HighlightRule.style` 字符串标识解析为**确定的渲染效果**（背景色/下划线/字色等），解析表 MUST 可枚举；对未知样式标识 MUST 回退到默认效果并保持可辨识，MUST NOT 静默不渲染。样式词表的来源与取值见 [待裁决：见 OPEN-QUESTIONS #16](./OPEN-QUESTIONS.md)。
- **FR-023**: 系统 MUST 提供**最小阅读工具栏**的呈现能力（MASTER.md §5.3）：默认隐形、鼠标静止 2.5 秒或移出后淡出、保留顶部热区、含返回/目录/进度/字号/行高/主题/单双页/书签/换源/设置这些入口。[待裁决：见 OPEN-QUESTIONS #8（§5.3 与 §7「工具栏=状态而非输入源」的边界）与 #9（2.5s/8px 未见于截图）]。系统 MUST 支持一组**确定的键位集**驱动工具栏唤出与翻页；键位表与 `Esc` 的语义分层见 [待裁决：见 OPEN-QUESTIONS #21](./OPEN-QUESTIONS.md)。
- **FR-024**: 系统 MUST 支持阅读区与 S3 外壳 UI 的**并屏共存**：阅读页内容 MUST 由本层渲染管线产出，MUST NOT 经由外壳 UI 框架（egui）的文本栈渲染正文字形。

#### 阅读痕迹与交互

- **FR-025**: 系统 MUST 把 S1 的字符区间痕迹（书签/高亮/批注）渲染为视觉标记，且 MUST 保证：渲染出的像素范围覆盖的字符集合**恰好等于**该区间；区间跨越页边界时 MUST 分页渲染且拼接无缝隙无重叠。
- **FR-026**: 系统 MUST 支持**文字选择**并把选择结果以字符区间（而非像素坐标）对外表达；选择口径 MUST 与 `ContentProvider::resolve_anchor` 的锚点口径一致。
- **FR-027**: 系统 MUST 支持在无界面环境下产生阅读记录所需的两个量（阅读秒数、阅读字符数）并交给 S1 既有接口落库；上报 MUST 节流且 MUST NOT 依赖任何界面（对齐 001 §FR-026b）。"阅读字数"的计算口径见 [待裁决：见 OPEN-QUESTIONS #15](./OPEN-QUESTIONS.md)。
- **FR-028**: 系统 MUST 支持命中测试（给定屏幕坐标得到字符位置），且 MUST 支持其反向（给定字符位置得到屏幕坐标）——两者 MUST 互为逆运算（在字形边界上的往返误差不大于半个字形）。
- **FR-029**: 系统 MUST 支持词典查词在阅读层的触发与结果呈现；词典求值本身 MUST 复用 001 §FR-016 的既有能力，本层 MUST NOT 实现第二套词典规则求值。

#### 渲染管线

- **FR-030**: 系统 MUST 实现阅读页的**自绘渲染管线**：字形缓存（按字体+字号+字形键复用）、行盒布局结果到绘制指令的转换、以及每页的绘制产出。管线 MUST 与排版计算分层：排版计算 MUST 可在无图形环境下独立完成（对齐宪法 IV「引擎必须能在无图形环境完整运行」）。
- **FR-031**: 系统 MUST 支持**分页预计算**：在当前阅读位置附近的章节 MUST 在后台预计算分页结果，使翻页时无需重新排版；预取 MUST 可取消且失败无副作用（对齐 001 `ContentProvider::prefetch` 的语义）。
- **FR-032**: 系统 MUST 支持**增量重排**：几何参数变化时，重排 MUST 只作用于受影响的页，且 MUST NOT 要求整章重新排版后才可呈现首帧。
- **FR-033**: 系统 MUST 实现翻页动效（含 MASTER.md §4 的 `--ease-spring` / `--dur-slow` 档位），并 MUST 在减少动效开启时降级为瞬时切换。
- **FR-034**: 系统 MUST 对**未覆盖字形**采取回退链（字体族内回退 → 系统回退 → 缺字占位），且回退 MUST NOT 改变该行其余字符的位置。
- **FR-035**: 系统 MUST 保证渲染的**稳定性**：同一页在同一参数下的两次渲染 MUST 产生相同的绘制指令序列（字形缓存命中状态除外），使像素快照比对可作为回归手段。
- **FR-036**: 系统 MUST 支持**图文混排**：图片行盒 MUST 按其显示尺寸参与分页计算（保证占位高度与最终一致），图片 MUST NOT 被页边界切开；图片不可用时 MUST 以占位呈现且 MUST NOT 中断正文排版。（该能力依赖 ContentProvider 的图片句柄，见 Context A 的契约缺口 → **[待裁决：见 OPEN-QUESTIONS #13](./OPEN-QUESTIONS.md)**）

#### 可测性与平台

- **FR-037**: 排版计算、分页、位置换算 MUST 能在**无图形环境**下全部执行成功（对齐 001 §SC-011 的同款要求，范围扩至本层）。
- **FR-038**: 系统 MUST 支持**离屏渲染**以产出可逐像素比较的图像，作为像素快照测试基础（AGENTS.md「排版层（S2）用像素快照测试」）；在图形后端不可用时 MUST 明确报告不可用并允许测试跳过，MUST NOT 伪装通过。
- **FR-039**: 系统 MUST 提供**可编程的验证入口**：给定书/章/参数/目标位置，输出分页结果、位置换算结果与（可选）渲染图像，供自动比对；该入口 MUST NOT 需要窗口系统。入口的形态（扩展 `tome-cli` 子命令 vs 仅库 API）见 [待裁决：见 OPEN-QUESTIONS #17](./OPEN-QUESTIONS.md)。
- **FR-040**: 系统 MUST 可在三个目标平台构建并运行：Windows 10 及以上、macOS 12 及以上、主流现代 Linux 发行版；三平台的排版结果 MUST 在同一字体与同一几何参数下一致（字形度量差异导致的亚像素差异不计入"不一致"）。
- **FR-041**: 系统 MUST NOT 包含遥测或崩溃上报；除用户明确触发的内容抓取外，MUST NOT 产生任何网络外发。字体获取 MUST NOT 触发网络请求。
- **FR-042**: 系统 MUST 在渲染后端不可用或字体不可用时明确报告并给出指引，MUST NOT 静默失败或黑屏（对齐 001 §FR-043 的报告风格）。
- **FR-043**: 系统 MUST 产出的错误沿用 001 的 `ErrorKind` 分类与可本地化错误标识，MUST NOT 硬编码面向用户的自然语言；对"本层不支持的能力" MUST 抛出可捕获的结构化错误（对齐 001 §FR-006）。

### Key Entities

- **排版参数集（ReadingConfig）**：一本书生效的阅读几何与呈现参数。分两个子集：**几何参数**（字号、行高、段布局模式与量、版心目标与上限、中缝、单双页模式）决定分页；**呈现参数**（主题、字体族、动效、噪声）只决定绘制。序列化后由 001 的 `Book.read_config` 承载；未设置时回退到全局默认与 MASTER.md §5.1 的默认值。
- **主题（Theme）**：由单一主题模块产出的语义 token 集合，含昼/夜两个实例。承载色彩、间距、圆角、阴影、动效常量与字体三角色（正文衬线 / UI 无衬线 / 规则等宽）。
- **段落（Paragraph）**：正文按换行符切分的单元。属性含段内文本、段样式（正文/标题/强调/居中）、以及在章节正文中的字符区间起点。
- **行盒（LineBox）**：排版产出的单行。属性含所属段、行内字符区间、行内字形簇序列及其相对位置、行高与基线、行内标点压缩量。
- **页（Page）**：分页产出的单元。属性含页码、所属章节序号、页内容所属的字符区间、行盒列表、双页模式下的左右页归属。
- **字形缓存条目（GlyphCacheEntry）**：按（字体、字号、字形键）索引的栅格化字形，含尺寸、偏移、来源（主字体或回退字体）。
- **渲染批次（RenderBatch）**：一页对应的绘制指令集合，由字形四边形、装饰（高亮/下划线/引用线）、图片四边形与背景构成；是实现"同一输入 → 相同指令序列"的载体。
- **字符位置映射（PositionMap）**：页内字符下标 ↔ 屏幕坐标的双向映射，供命中测试、文字选择与光标定位使用；是 FR-028 的载体。
- **痕迹区间（TraceRange）**：消费自 S1 的字符区间（书签/高亮/批注），在排版结果上被解析为若干"本页内的可见片段"。

## Out of Scope（明确排除）

本规格以 001 已划定的边界为准，并补充 S2 自身的排除项。

### 由 001 划定、S2 继承

- **WebView 类书源能力**：以结构化错误降级，不实现内嵌浏览器
- **PDF、UMD 格式**；压缩包扫描导入
- **RSS 订阅阅读、朗读（TTS）、定时任务调度**：S4
- **音频播放、漫画、视频**：S4 且默认不启用
- **编程接口服务（HTTP/WebSocket/MCP）**：v1 无消费方
- **应用自动升级、跨设备同步、WebDAV、局域网传输**
- **遥测、崩溃上报、任何形式的使用数据外发**
- **书源变更追踪**

### 本规格自身的排除

- **不做完整浏览器内核级排版**：不实现 CSS 盒模型、浮动、绝对定位、表格自动布局、多列流（`column-count` 语义）、flex/grid 排版。本层排版的对象是**已净化的纯文本 + 少量行内样式**，不是 HTML/CSS 文档。
- **不做 PDF 排版引擎级功能**：不做分栏流、跨页脚注/尾注排版、章节级目录分页（参考文献、索引的自动生成）、页面级锁定与精确定位、印前出血与装订标记。
- **不做复杂版式**：不做文字绕图（不规则环绕）、不做多栏杂志式版式、不做首字下沉、不做页边注。
- **不做字体编辑与字体文件生成**：不实现字体子集化工具、不实现字形轮廓编辑。
- **不做 S3 的外壳页面**：书架、书源管理、设置三个页面的布局与组件属 S3；MASTER.md §6 中除阅读器外的自适应规则属 S3。
- **不做阅读器周边的非阅读功能**：书内搜索（S1 已提供数据，界面归 S3）、笔记总览页、阅读统计图表、导出成图片/PDF。
- **不做打印与导出为固定版式**（与"不做 PDF 排版引擎"同源）。
- **不做竖排与右起排版**：见 [OPEN-QUESTIONS #6](./OPEN-QUESTIONS.md)（当前按"不做"处理，待裁决）。
- **不做滚动阅读模式**：见 [OPEN-QUESTIONS #7](./OPEN-QUESTIONS.md)（当前按"样式稿只有翻页、S2 只做翻页"处理，待裁决）。
- **不做多窗口内的多本书同屏阅读**：单阅读视图。
- **不做用户自定义字体文件导入**：字体策略待裁决，见 [OPEN-QUESTIONS #3](./OPEN-QUESTIONS.md)。
- **不做分页结果的持久化**：分页结果按 FR-031 在内存中预计算，不落盘。理由与备选方案见 [OPEN-QUESTIONS #18](./OPEN-QUESTIONS.md)。
- **不做"剩余阅读时间"的估算**：`design-system/preview.html` 页脚有此展示，但 MASTER.md 未定义其估算口径 → 见 [OPEN-QUESTIONS 附录 A8](./OPEN-QUESTIONS.md)。

## Success Criteria *(mandatory)*

### Measurable Outcomes

**中文排版正确性**（口径：见下）

- **SC-001**: 中文排版规则清单中的**每一条**均有判定例与反例，且全部通过（100%）。清单条目数在实现时确定并记录，测试逐条一一对应。
- **SC-002**: 在标点密集的合成语料（每百字含不少于 15 个全角标点）下，行首禁则与行尾禁则的**违反次数为 0**（允许的例外必须在 FR-006 清单中显式列出并计数）。
- **SC-003**: 中西文混排语料下，无任一行超出容器宽度（100%）；西文单词的断裂只发生在 FR-007 允许的两种情形（整词放不下、单词长于整行）。

**位置不变量**

- **SC-004**: 锚点与排版参数无关：对同一锚点在一组排版参数组合（至少覆盖 字号 14/19/24/30 × 行高 1.4/1.85/2.2 × 单页/双页 × 段缩进/段间距）下的重排结果，锚点值 100% 不变，且重排后该字符 100% 落在某页的可见字符区间内。（口径：参数化验证，无需真实改变窗口尺寸——沿用 001 §SC-008 的验证方式）
- **SC-005**: 分页结果对主题与呈现参数**完全无依赖**：同一几何参数下，昼/夜主题、不同字体族、不同动效开关产出的页序列（字符区间）100% 相同。

**分页完整性**

- **SC-006**: 分页结果**不丢字不重字**：把一页页的字符区间按序拼接，得到的字符串与该章正文**逐字符相等**（100%）。留白补足产生的空白页不计入内容区间，但必须被显式标记为"书页语义留白"而非内容页。

**性能**（每条标注测量口径）

- **SC-007**: 翻页响应：在已预计算当前章分页结果的前提下，从"请求第 N 页"到"该页首个可呈现帧"的时间 **≤ 16 ms**（口径：预热后的稳态测量，取中位数；含几何变换与字形缓存命中，不含动效时长）。@ [待裁决：见 OPEN-QUESTIONS #10](./OPEN-QUESTIONS.md)
- **SC-008**: 首屏：从"打开一本书"到"首章首屏可呈现"的时间 **≤ 400 ms**（口径：章节内容已在本机缓存或为本地书；含排版 + 分页 + 首屏渲染；不含网络抓取时间，抓取时间属 001 §SC-001 的度量）。@ [待裁决：见 OPEN-QUESTIONS #10](./OPEN-QUESTIONS.md)
- **SC-009**: 重排响应：修改字号或行高后，从"参数生效"到"新的一页可呈现" **≤ 150 ms**（口径：中位章节规模约 3000 字，含重新分页与渲染；不含用户连续拖动的中间帧）。@ [待裁决：见 OPEN-QUESTIONS #10](./OPEN-QUESTIONS.md)
- **SC-010**: 内存：排版结果常驻内存与章节字符数的比值受控——单章排版结果（行盒 + 位置映射）的内存占用 **≤ 章节字节数 × 8**（口径：进程内实测的堆分配差值，不含字形缓存与纹理）。超长章节（≥ 20 万字）下不得因单章过大而失败。

**渲染与可测性**

- **SC-011**: 像素快照回归：对固定的合成语料与固定参数，离屏渲染产出的图像与基线快照的差异像素比例 **≤ 0.1%**（口径：同一平台、同一字体集合、同一后端；跨平台不比较像素，只比较排版结构）。图形后端不可用时该判据**跳过并显式报告**，不计为通过。
- **SC-012**: 渲染稳定性：同一页在同一参数下连续两次渲染的绘制指令序列**逐条相同**（100%；字形缓存首次预热造成的差异必须在第二次之前消除）。
- **SC-013**: 痕迹渲染精确性：对合成语料中一组已知字符区间的痕迹，渲染出的高亮/下划线像素范围覆盖的字符集合与其字符区间**逐字符相等**（100%），含跨页区间。

**无图形环境与平台**

- **SC-014**: 在无图形环境的系统上，本层**全部排版与位置换算能力**可被调用且无图形相关失败（100%）；离屏渲染能力在该环境下若不可用，必须报告不可用（不得伪造成功）。
- **SC-015**: 三个目标平台均能构建并产出可运行产物（100%）；同一字体与几何参数下的**分页结构（页数与每页字符区间）三平台一致**（100%）。

**合规与体积**

- **SC-016**: 任何时刻不存在非用户动作触发的网络外发（100%），字体获取不构成例外。
- **SC-017**: 本层引入的二进制体积被记录在案，并作为最终 `<20 MB` 目标基线的输入之一移交 S3；本层 MUST NOT 引入与功能无关的体积膨胀（未使用的静态依赖、重复的排版实现、为单平台打包的冗余资源）。具体取舍见 [OPEN-QUESTIONS #3](./OPEN-QUESTIONS.md)。

## Assumptions

### 已批准的技术约束（来自 001 plan/research 与 design-system，供规划阶段承接）

- 渲染路线为 **wgpu 自绘管线**：阅读页的字形缓存、分页、翻页动效由本层实现，**不经即时模式 UI 框架（egui）的文本栈**；egui 只承担外壳 UI。（001 plan §Technical Context / 001 spec §Assumptions；MASTER.md §10）
- 排版基座为 **cosmic-text 做字形整形**，叠加**自研中文排版规则**（标点挤压、避头尾、禁则）。（001 plan §Technical Context；用户指令）
- 主题以**单一 `theme` 模块产出 `Theme` 结构体**、昼/夜两实例承载，禁止各控件散读常量。（MASTER.md §10）
- 单双页切换以 **em 制 `measure` 计算**而非窗口宽度；字号/行高变化触发重排并复原字符锚点。（MASTER.md §5.2 / §10）
- 动效统一 `Duration`/`Easing` 常量；`prefers-reduced-motion` 有对等开关。（MASTER.md §4 / §10）
- 无障碍（焦点环、键盘导航、对比度）为**引擎级强制**，非可选皮肤。（MASTER.md §10）
- 布局引擎用「容器宽度 → 列数/分栏」的连续函数，不用断点表。（MASTER.md §6 / §10）
- 排版层测试用**像素快照**；引擎层用输入→输出断言。（AGENTS.md §测试）
- 阅读痕迹以**字符区间**表达，不使用渲染坐标。（001 §FR-028；MASTER.md 未涉及，由 001 主导）
- 依赖方向单向，本层落点为 `tome-reader`，只依赖 `tome-core` 的接缝 trait。（AGENTS.md §架构铁律；001 plan §Dependency Graph）

### 与已批准基线存在张力的两处（须规划阶段承接）

- **字体内嵌**：MASTER.md §10 要求"打包内嵌字体（衬线正文 + 无衬线 UI + 等宽），确保三平台一致；注意 <20MB 体积预算"，而 001 §Assumptions 明确"不捆绑任何字体；依赖系统字体并在缺失时给出明确指引"。两者**不直接冲突**（001 说的是"缺字体时给指引"，MASTER 说的是"内嵌以保证三平台一致"），但对体积的取舍方向相反。→ **[待裁决：见 OPEN-QUESTIONS #3](./OPEN-QUESTIONS.md)**
- **正文字体族与段落缩进**：MASTER.md §3 的 `--font-reading` 字体栈以宋体类衬线为首选，而 `preview.html` 的正文样例段落**无首行缩进**且段间有间距，§5.1 却把"段首缩进 2em"列为默认。二者在有"二选一"开关的前提下不算冲突，但**默认值取哪个**需裁决。→ **[待裁决：见 OPEN-QUESTIONS #12](./OPEN-QUESTIONS.md)**

### 其他假设

- **目标用户为单机单用户**：不涉及多用户与协作；性能目标按单机桌面场景设定。
- **测试语料为合成文本**：入仓库的是手工构造的合成语料（覆盖各排版规则点）；真实书籍文本不入仓库（第三方资产）。
- **不做 DRM**：受保护内容由 001 明确拒绝，本层不涉及。
- **阅读视图一次只呈现一本书的一章**：不做多书或跨章同屏。
- **本层不决定最终应用体积**：`<20 MB` 目标基线的最终裁决在 S3（001 §SC-009 已如此声明）。
- **颜色与主题的最终视觉取舍以 `design-system/shots/*.png` 为准**：本规格作者未读图，凡涉及"图上实际是什么样子"的断言均已列入待核对清单（见 [OPEN-QUESTIONS.md 附录](./OPEN-QUESTIONS.md)）。
- **上游行为不构成本层约束**：排版是桌面端新增能力（001 明确"上游没有而桌面该有的能力应当补上"），无兼容性基线可对；故本层的规则依据是**公开的排版规范与设计稿**，不是上游实现。干净室纪律照旧（不得阅读上游源码）。
