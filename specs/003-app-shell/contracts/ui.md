# S3 应用外壳 — UI 契约（contracts/ui.md）

**Date**: 2026-10-11 | **Spec**: [spec.md](../spec.md) | **Data Model**: [data-model.md](../data-model.md)

桌面应用的对外契约 = 视图契约（什么状态下用户看到什么、能做什么）+ 键盘契约 + 文案契约 + 呈现不变量。测试以「视图状态机 + 消息协议」的 headless 断言为主（不依赖像素）；像素级一致由 S2 快照体系覆盖。

## 1. 视图契约

### 1.1 书架视图（AppView::Shelf）

| # | 状态 | 用户看到 | 可做 | 契约断言 |
|---|---|---|---|---|
| V1 | 空书架 | MASTER 空态：引导插画位 +「导入本地书」主按钮 + 书源导入次按钮 | 导入（本地/书源）、打开设置 | 空态必有下一步动作引导（spec Edge Case） |
| V2 | 有书 | 虚拟化网格书卡（封面/标题/作者/进度%）、过滤框、排序切换 | 打开/移除（需确认）/过滤/排序/滚动 | 1000 册 60fps（SC-005）；封面缺失走 MASTER 占位形态 |
| V3 | 搜索中 | 结果按源分组流式到达、每组带源名、可取消 | 点结果看详情、取消、加入书架 | 只呈现当前 generation（DM §2 不变量 4）；首屏 ≤3s（SC-007） |
| V4 | 详情 | 简介/目录/「加入书架」主按钮 | 加入书架、返回结果 | 加入后书架出现该书（进度 0%） |

### 1.2 阅读视图（AppView::Reading）

| # | 状态 | 用户看到 | 可做 | 契约断言 |
|---|---|---|---|---|
| R1 | 加载中 | LoadingSkeleton（MASTER 骨架）+ 可取消 | 取消返回书架 | 不白屏（FR-010）；超大章节不假死 |
| R2 | 阅读中 | 版心（单/双页或滚动）、页脚（章标题 + 进度）、可选抽屉 | 翻页/滚动、五组调整、唤出抽屉、返回书架 | 调整即时生效 ≤150ms 且锚点 100% 不变（SC-006）；抽屉不改版心几何 |
| R3 | 加载失败 | 结构化错误（标识 + 文案）+ 可行动作 | 重试 / 换源 / 返回 | 错误必有动作（DM §2 不变量 6）；标识永不翻译 |
| R4 | 章间边界 | 翻页末页→下章首页、滚动章末自动接续 | 自然继续阅读 | 接续锚点连续（FR-006b）；接续加载同 R1/R3 |
| R5 | 抽屉-目录 | 完整目录、当前章高亮 | 跳章、切书签页签、关闭 | 跳转后目标章首字符可见 |
| R6 | 抽屉-书签 | 书签列表（预览文本 + 时间） | 存书签、跳转、删除（确认） | 书签按书持久化；失效锚点按钳制定位 |

### 1.3 设置叠加层（SettingsOverlay）

四组且仅四组：主题（昼/夜/跟随系统）、默认字号与行高（步进器）、默认阅读形态、默认单双页；快捷键表只读展示。保存即持久化，重启生效（SC-012）。

## 2. 键盘契约（FR-017 / SC-008）

| 上下文 | 键 | 动作 |
|---|---|---|
| 全局 | `Tab` / `Shift+Tab` | 焦点顺序移动（egui 内建导航） |
| 书架 | `Enter` | 打开选中书卡 |
| 书架 | `/` 或 `Ctrl+F` | 进入过滤框 |
| 书架 | `Del` | 移除选中（弹确认） |
| 阅读 | `←` / `→`（PgUp/PgDn 同义） | 翻页（滚动形态为逐视口） |
| 阅读 | `↑` / `↓` / `Space` / `Shift+Space` | 滚动形态滚行/屏 |
| 阅读 | `Ctrl+=` / `Ctrl+-` | 字号步进 |
| 阅读 | `Ctrl+M` | 翻页 ⇄ 滚动 |
| 阅读 | `Ctrl+B` | 抽屉（目录页签）；`Ctrl+Shift+B` 抽屉（书签页签） |
| 阅读 | `Ctrl+D` | 存书签 |
| 阅读 | `Ctrl+L` | 昼 ⇄ 夜 |
| 阅读 | `Esc` | 关抽屉 → 再按返回书架（EscLayer 语义复用 tome-reader keys 既有分层） |
| 任意 | `Ctrl+,` | 设置叠加层 |

**规则**：快捷键表内置且在设置视图可查阅（FR-017）；每个可交互元素有可见焦点态（自绘 2px 环 + 2px offset，仅键盘来源显示，R8）；`Ctrl+K` **不得出现**（命令面板延后 D3，R3 gap）。

## 3. 文案契约（FR-019 / R10）

1. 界面全部文案出自 `tome-app/src/i18n.rs` 文案表（zh 主）；组件内**零字面值**（守卫：grep 断言组件文件无中文字面串）。
2. 引擎错误以 `error.xxx` 标识抵达，文案表做 `id → 文案` 映射；**标识本身永不翻译**且随文案一并呈现（可捕获、可检索）。
3. 能力错误呈现 `[capability: xxx]` 标识（对齐 002 §2.3 形态）。
4. 数字/进度/时间的呈现格式统一在文案表（不在组件内拼格式）。

## 4. 呈现不变量（机检口径）

1. **MASTER 合规**（SC-011）：配色/间距/圆角/动效只取 `tome_core::theme` token；对比度断言 **≥4.5**（非精确相等，R7）；鎏金禁作文本前景；text-tertiary 禁用于必要信息；border-strong 不作唯一可见边界；badge 按 R7 重建。
2. **静态帧零重绘**：`content_version` 未变时 PaintCallback 不触发 S2 重渲染（纹理缓存命中）。
3. **单双页阈值**：窗口宽 ≥ 1512px（19px 字号，含 2×sp-10）才允许双页呈现（R8 口径修正）；低于阈值自动单页且明示。
4. **主题一致性**：`FollowSystem` 时 OS 主题变化 → Day/Night token 即时切换，页序列字符区间不变（002 SC-005 对齐）。
5. **依赖图**：`tome-app` 仅依赖 `tome-core`（+ tome-reader 的排版/渲染面，与 tome-cli 同口径的组合根豁免，dependency_graph.rs 排除名单同步更新）。
