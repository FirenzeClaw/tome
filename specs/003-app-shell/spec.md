## 项目定位与范围切刀（访谈裁决记录）

S3 把 S1 引擎内核（书源管线/本地书/存储/锚点契约）与 S2 排版渲染层（双形态排版/渲染/主题）经桌面外壳变成**用户可日常使用的桌面阅读器**。

三轮范围切刀（2026-10-11 用户逐条裁决，均选 A）：

1. **范围**：S3 = **阅读主线**（书架 + 阅读界面 + 书源最薄获取层 + 最小设置）。书源管理面板做厚为独立延后项 **D1**（`project/backlog/s3_deferred_items`）。
2. **窗口形态**：**单窗口双视图**——书架视图 ⇄ 阅读视图互斥切换；目录/书签以**抽屉式覆盖侧栏**唤出（不占版心宽）；阅读区单页/双页可切 + 翻页/滚动双形态。三栏常驻与多窗口为延后项 **D2**。
3. **书源最薄一层**：外壳内闭环「本地书导入 + 书源导入（文件/URL/剪贴板）+ 搜索→详情→加入书架 + 正文加载 + 换源」；**不做**书源列表面板、启停/分组、源检查、书源编辑、登录源、发现页浏览（全部进 D1）。

**干净室纪律**：与 001/002 同一红线——上游 `D:/Code/legado` 禁读任何 `.kt`/`.kts`/`.java` 源码（唯一例外 `avd.bat`/`avd.sh` 与 `gradle/libs.versions.toml`）。外壳层的交互语义依据本项目规格与 `design-system/MASTER.md` 独立推导。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 书架与本地书阅读闭环 (Priority: P1)

用户启动应用看到书架。把一份 TXT/EPUB 文件拖入（或经导入按钮选择）后，书出现在书架上；点开即进入阅读视图开始阅读；读到一半关掉再打开这本书，回到上次离开的位置；不需要了能从书架移除。

**Why this priority**: 这是「能读书」的最小闭环——没有它其它一切（书源、调整、设置）都没有附着点。书架是应用的进出点，阅读是存在理由，进度记忆是阅读器的及格线。

**Independent Test**: 启动应用 → 导入一本 TXT → 打开读到第 N 章 → 关闭阅读视图回书架 → 重新打开 → 位置精确恢复（字符锚点不变）。单独交付即可用（书源功能缺席不影响本故事）。

**Acceptance Scenarios**:

1. **Given** 空书架，**When** 用户导入一本 TXT 文件，**Then** 该书以封面卡片出现在书架上（标题/作者/进度 0%），导入到可打开不超过 3 步
2. **Given** 书架上有书，**When** 用户点击书卡，**Then** 进入阅读视图并渲染首章首屏（S2 排版管线），耗时满足 SC-002
3. **Given** 阅读到某章某位置，**When** 用户返回书架再重新打开该书，**Then** 阅读视图直接定位到离开时的字符锚点，位置值与离开前完全一致
4. **Given** 书架上有书，**When** 用户选择移除并确认，**Then** 该书从书架消失，其缓存内容按 S1 存储语义清理
5. **Given** 书架有 1000 册，**When** 用户滚动与按标题过滤，**Then** 滚动与过滤响应满足 SC-005

### User Story 2 - 阅读中的个性化调整 (Priority: P2)

用户在阅读视图内随时调整字号、行高、翻页⇄滚动形态、单页⇄双页、昼⇄夜主题——全部不离开阅读视图、即时生效，且调整前后正在读的那一段文字不丢位置（锚点保持）。

**Why this priority**: 阅读器的日常高频操作。S2 已验收锚点不变量（002 SC-004/005b），外壳若接不住，S2 的不变量就白做了（同 002 US1 的论证结构）。

**Independent Test**: 打开任意书 → 在阅读视图内逐一改动五组参数 → 每次改动后当前字符锚点值不变且仍可见；翻页⇄滚动切换后位置不变。不依赖 US1 的书架（可用测试书直进阅读视图）。

**Acceptance Scenarios**:

1. **Given** 阅读视图中，**When** 用户调大字号，**Then** 版心即时重排（SC-006 时延内），调整前锚定的字符在新版心中可见且锚点值不变
2. **Given** 翻页形态阅读中，**When** 用户切换为滚动形态，**Then** 视图变为连续滚动，当前字符出现在视口内且锚点值不变（对齐 002 SC-005b）
3. **Given** 阅读视图中，**When** 用户切换单页⇄双页，**Then** 阅读区在单页与跨页（spread）间切换，当前字符保持可见
4. **Given** 阅读视图中，**When** 用户切换昼⇄夜主题，**Then** 界面与阅读区配色即时反转（MASTER.md 的昼夜 token），页序列字符区间不变（对齐 002 SC-005）
5. **Given** 任一调整生效，**When** 用户重启应用再打开该书，**Then** 该书的阅读参数按「跟随该书最近设置」或「跟随全局默认」的既定规则呈现（见 FR-007b 的规则定义）
6. **Given** 阅读视图中，**When** 用户唤出抽屉把当前位置存为书签、继续阅读数章后从书签页签跳回，**Then** 视图定位到书签的字符锚点且该字符可见；删除书签需确认，重启应用后书签仍在

### User Story 3 - 网络书源获取闭环 (Priority: P3)

用户把一个书源文件（或 URL、剪贴板内容）导入应用；在书架视图搜索关键词，结果来自已导入的书源；点开某条结果看详情（简介/目录），选「加入书架」后它出现在书架上；点开阅读，正文按章加载；当前源失效时能换到另一个可用源继续读同一本书。

**Why this priority**: 「书源生态开箱即用」是项目核心差异化价值，但它是获取路径而非阅读本身——P1/P2 先保证「有了书怎么读」，本故事保证「书从哪来」。薄层闭环即可，管理动作（D1）不在此列。

**Independent Test**: 导入一份合成书源（仓库既有测试源）→ 搜索关键词 → 详情 → 加入书架 → 阅读一章 → 模拟当前源失效 → 换源成功继续阅读。与 US1/US2 无依赖（书架能力由 US1 提供接口即可联调）。

**Acceptance Scenarios**:

1. **Given** 无任何书源，**When** 用户导入书源文件（或粘贴 URL/剪贴板文本），**Then** 书源可用（经 S1 source import 语义落注册表），失败时给出结构化错误原因（不留无提示失败）
2. **Given** 已导入书源，**When** 用户在书架视图输入关键词搜索，**Then** 结果按源分组列出（书名/作者/封面有则显示），响应满足 SC-007
3. **Given** 搜索结果中选中一条，**When** 查看详情并选择加入书架，**Then** 该书进入书架，进度 0%
4. **Given** 书架上的网络书籍，**When** 用户打开阅读，**Then** 首章正文经 S1 content 管线（含净化）加载并进入排版，加载中有明确加载态（不白屏）
5. **Given** 阅读中当前源章节加载失败，**When** 用户触发换源，**Then** 应用列出同书名的其它可用源，切换后从相同章节位置继续阅读（锚点经 S1 换源语义映射）

### User Story 4 - 键盘可达与最小设置 (Priority: P4)

用户只用键盘完成书架与阅读的全部核心操作（打开书、翻页/滚动、目录跳转、调整参数、返回书架）；在设置视图修改四组全局默认（主题/默认字号行高/默认阅读形态/默认单双页），重启后仍生效。

**Why this priority**: 桌面效率与无障碍的及格线（访谈锚点 #7/#8）。排在最后因为它依附于前三个故事的界面存在，但它约束那些界面的实现方式（焦点管理、快捷键表），不是可后贴的皮。

**Independent Test**: 全程不用鼠标完成「打开书→读两页→改字号→回书架」；改设置→重启→生效。可独立于书源故事测试。

**Acceptance Scenarios**:

1. **Given** 应用任意视图，**When** 用户只用键盘，**Then** 焦点顺序符合 MASTER.md 的焦点规范，每个可交互元素可达且有可见焦点态
2. **Given** 阅读视图，**When** 用户按翻页/滚动/目录/返回的快捷键，**Then** 对应动作发生（快捷键表内置且可在设置视图查看）
3. **Given** 设置视图，**When** 用户修改四组默认之一并离开，**Then** 新默认值对之后打开的书生效（已有书按 FR-007b 规则处理），重启应用后设置保持
4. **Given** 任何视图，**When** 用户触发应用级动作（如「导入书」），**Then** 存在对应键盘路径，无需指针设备

### Edge Cases

- **导入坏文件**：TXT 编码无法识别、EPUB 结构损坏 → 给出具体失败原因（经 S1 local 错误分类），书架不留半成品条目
- **打开超大章节**（≥ 20 万字）：经 S2 FR-026 的按需释放与 002 SC-010 约束，界面不得假死；加载期间可取消返回书架
- **网络全程离线**：搜索/书源导入（URL）/正文加载给出「网络不可用」结构化错误；本地书与已缓存内容不受影响
- **书源返回异常内容**（空正文/乱码/脚本错误）：经 S1 错误分类如实上报（标识式，不硬编码自然语言），可换源或返回
- **窗口尺寸极端**（很窄/拖到超宽）：阅读区按 MASTER.md 的响应式规则重排，版心几何实时适配，锚点保持
- **同一本书重复导入**：按 S1 存储语义识别为同一条目（更新而非重复卡片）
- **书架为空/搜索无结果/目录为空**：空态按 MASTER.md 的空态规范呈现，给出下一步动作引导
- **单章内容损坏或引擎异常**：排版/解析在单章上的失败 MUST 被隔离在该章（结构化错误 + 可跳过该章继续阅读），MUST NOT 使应用整体崩溃；引擎 panic 经外壳兜底捕获并按错误分类呈现
- **第二个实例**：用户在应用已运行时再次启动，MUST 激活已有实例而非打开第二个窗口（默认裁决；两个实例写同一数据目录的竞态在源头消除）
- **书签锚点失效**（书内容变更后锚点越界）：按 S2 的钳制语义定位到最近有效字符，不报错不丢书

## Requirements *(mandatory)*

### Functional Requirements

**书架（US1）**

- **FR-001**: 应用启动 MUST 呈现书架视图，列出全部在架书籍（封面卡片：标题/作者/进度），空书架给出引导空态。
- **FR-002**: 用户 MUST 能导入本地书（TXT/EPUB/MOBI 经 S1 local 能力，含拖入与文件选择两种路径），导入失败 MUST 给出结构化原因，书架 MUST NOT 留下不可打开的半成品条目。
- **FR-003**: 用户 MUST 能打开任一书卡进入阅读视图；系统 MUST 恢复该书上次阅读位置（`(chapter_index, char_offset)` 锚点，经 S1/S2 锚点契约）。
- **FR-004**: 用户 MUST 能从书架移除书籍（需确认）；移除后其缓存内容按 S1 存储语义清理。
- **FR-005**: 书架 MUST 支持按标题过滤与按最近阅读/标题排序；1000 册规模下滚动与过滤满足 SC-005。

**阅读视图（US2）**

- **FR-006**: 阅读视图 MUST 经 S2 排版渲染管线呈现章节（翻页与滚动双形态、单页与双页可切），任一时刻只呈现一种形态组合，且 MUST 显示当前章标题与阅读进度。
- **FR-006b**: 章间接续 MUST 自然成立：翻页形态下末页再翻进入下一章首页（首页前翻进入上一章末页）；滚动形态下滚过章末自动接续下一章（前滚过章首接续上一章）；接续加载遵守 FR-010 的加载态与错误呈现，锚点连续不丢位置。
- **FR-007**: 用户 MUST 能不离开阅读视图调整：字号、行高、翻页⇄滚动、单页⇄双页、昼⇄夜主题；每次调整 MUST 即时生效（SC-006 时延内）且**当前字符锚点值不变、调整后可见**（对齐 002 SC-004/005/005b）。
- **FR-007b**: 阅读参数的取值规则（本地书与网络书同一规则）：书**首次**打开用全局默认（FR-018）；之后每本书记住自己的最近调整——「跟随该书最近设置」覆盖「跟随全局默认」，全局默认的后续修改**不**回写已读过的书。
- **FR-008**: 用户 MUST 能唤出抽屉式覆盖侧栏；侧栏含**目录**与**书签**两个页签。侧栏 MUST NOT 改变版心几何（覆盖式，不挤压阅读区）；抽屉开合动效遵循 `design-system/MOTION.md`。
- **FR-008b**: 目录页签 MUST 展示当前书完整章节目录并支持跳转到指定章（含当前章高亮）。
- **FR-008c**: 书签页签 MUST 支持：把当前阅读位置存为书签（带位置预览文本）、跳转到任一书签位置、删除书签。书签按书持久化（经 S1 存储），删除需确认。
- **FR-008d**: 书签跳转与目录跳转 MUST 走同一锚点定位路径（`(chapter_index, char_offset)`），跳转后该字符可见。
- **FR-009**: 阅读位置 MUST 持续记忆：翻页/滚动改变位置时按节流策略落盘（经 S1 存储），异常退出（杀进程）后位置损失 ≤ 一个节流窗口。
- **FR-010**: 章节内容加载（本地解析或网络抓取）期间 MUST 显示明确加载态（不白屏），加载失败 MUST 给出结构化错误与可行动作（重试/换源/返回）。
- **FR-011**: 窗口尺寸变化 MUST 触发版心几何实时适配（响应式规则按 MASTER.md），适配过程锚点保持。

**书源薄层（US3）**

- **FR-012**: 用户 MUST 能导入书源（文件/URL/剪贴板文本三径，经 S1 source import 语义）；失败 MUST 给出结构化原因。
- **FR-013**: 用户 MUST 能在书架视图发起关键词搜索（经 S1 search 管线，覆盖全部已导入书源——书源启停属延后项 D1，本层不存在「不可用」的源），结果按源分组呈现；搜索 MUST 可取消。
- **FR-014**: 用户 MUST 能从搜索结果查看书籍详情（简介/目录）并加入书架；加入后按新书处理（进度 0%，阅读参数按 FR-007b 规则）。
- **FR-015**: 网络书籍的正文 MUST 经 S1 content 管线逐章加载（含净化）；已加载章节按 S1 缓存语义复用，重复打开不重复抓取。
- **FR-016**: 当前源章节加载失败时，用户 MUST 能触发换源：系统列出同书名的其它可用源（经 S1 换源语义），切换后从相同阅读位置继续（锚点映射）。

**键盘与设置（US4）**

- **FR-017**: 书架与阅读视图的**全部核心操作** MUST 可纯键盘完成（打开/翻页/滚动/目录/书签/调整/返回/导入/搜索），焦点顺序与焦点态遵循 MASTER.md；快捷键表 MUST 内置并可在设置视图查看。
- **FR-018**: 设置视图 MUST 提供且仅提供四组全局默认：主题（昼/夜/跟随系统）、默认字号与行高、默认阅读形态（翻页/滚动）、默认单双页；设置 MUST 持久化（经 S1 配置注入），重启生效。
- **FR-019**: 界面全部文案 MUST 来自应用层的文案表（引擎层零自然语言的既有红线不变——对齐 002 FR-058 精神，外壳层是其唯一合法文案来源）。

**外壳基座**

- **FR-020**: 应用为**单窗口双视图**：书架视图 ⇄ 阅读视图互斥切换；切换 MUST 保持各自状态（书架的滚动位置与过滤词、阅读的位置与参数）。
- **FR-021**: 界面 MUST 100% 遵循 `design-system/MASTER.md`（组件/配色/排版/动效 token）——不另起炉灶，无 MASTER 无依据的自定义样式。
- **FR-022**: 外壳 MUST 经 tome-core 的接缝 trait 消费 S1/S2 能力（架构铁律：tome-app 永不直接构造 tome-source/tome-store 内部类型）；引擎能力的任何缺失 MUST 以结构化能力错误呈现（标识式，可捕获，不伪造成功——对齐 002 FR-053）。
- **FR-023**: 冷启动到书架可交互 MUST 满足 SC-001；启动期 IO 失败（数据目录不可写/库损坏）MUST 按 S1 FR-043 语义明确报告与指引。

### Key Entities *(include if feature involves data)*

- **书架条目（ShelfEntry）**：一本书的在架呈现。属性：书籍标识、标题、作者、封面（有则）、来源类别（本地/网络源）、当前进度（锚点 + 百分比）、最近阅读时刻。关系：本地书 ↔ S1 库根条目；网络书 ↔ 书源 + 书籍 URL。
- **阅读进度（ReadingProgress）**：一本书的阅读位置与参数快照。属性：`(chapter_index, char_offset)` 锚点、更新时间、该书最近的阅读参数（字号/行高/形态/单双页/主题）。节流落盘。
- **用户设置（UserSettings）**：四组全局默认（FR-018）。持久化于数据目录配置（S1 配置注入）。
- **书源引用（SourceRef）**：一条已导入书源的外壳视图。属性：源标识、名称、可用性。外壳不持有源定义本体（S1 注册表持有）。
- **搜索结果（SearchHit）**：一次搜索的一条命中。属性：源、书名、作者、封面（有则）、书籍 URL。按源分组呈现。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 冷启动到书架可交互 **≤ 1.5 s**（本机数据已建；口径：进程启动到书架视图可响应输入）。
- **SC-002**: 打开书到首屏可阅读 **≤ 400 ms（目标）/ 800 ms（红线）**（沿用 002 SC-008 口径：内容已在本机；含排版+分页+首帧；不含网络抓取）。
- **SC-003**: 本地书导入到开始阅读 **≤ 3 步**（步 = 用户动作：点击/拖入/按键一次）。
- **SC-004**: 搜索→详情→加入书架→开始阅读 **≤ 4 步**。
- **SC-005**: 书架 1000 册下滚动与标题过滤保持 **60 fps**（掉帧率 < 1%，按帧时间分布计）。
- **SC-006**: 阅读参数调整即时生效 **≤ 150 ms**（沿用 002 SC-009 口径：参数生效到新帧可呈现，中位数）；调整后锚点值 **100% 不变**且该字符 100% 可见。
- **SC-007**: 关键词搜索从发起到首屏结果 **≤ 3 s**（口径：单源典型网络时延内；全部源的最终结果可陆续到达，首屏不等待全部）。
- **SC-008**: 键盘可达性：书架与阅读的**全部核心操作**（FR-017 清单）可纯键盘完成，**100%**；每个可交互元素有可见焦点态（按 MASTER.md 焦点规范逐项核对）。
- **SC-009**: 位置记忆可靠性：正常退出后重新打开，阅读位置 **100% 精确恢复**（锚点值逐字符相等）；异常退出（杀进程）后位置回退 ≤ 一个节流窗口。
- **SC-010**: 视图切换状态保持：书架 ⇄ 阅读往返后，书架滚动位置/过滤词与阅读位置/参数 **100% 保持**。
- **SC-011**: 设计规范合规：界面组件/配色/排版/动效 **100%** 出自 `design-system/MASTER.md` token 与组件（逐项对照检查表，无自由发挥样式）。
- **SC-012**: 设置持久化：四组默认修改后重启应用 **100% 保持**；新书默认按全局设置打开，旧书按该书最近设置打开（FR-007b 规则）100% 符合。

## Assumptions

- 目标平台为 Windows 10+ / macOS 12+ / 现代 Linux 的桌面环境（与 001/002 同一承诺）；移动端与竖排不在本层范围。
- 用户以单窗口单任务方式使用（一次读一本书）；多窗口与同屏对照为延后项 D2。
- S1/S2 的全部已验收能力（锚点契约、双形态排版、渲染、存储、书源管线、本地书解析、配置注入、错误分类）可直接消费，其语义不在本层重新定义；本层只做呈现与编排。
- 界面文案为中文为主（引擎层零自然语言，文案表在外壳层）；多语言框架不在本层范围。
- 用户数据（书架/进度/设置/缓存）存于 S1 数据目录语义（可移植模式优先）；本层不引入第二份存储。
- 网络可用性由用户环境决定；离线时网络相关功能如实报错（见 Edge Cases），本地功能不受影响。
- 体积基线已由用户裁决允许跨越（2026-10-11，`size-report.md` 落账）；本层体积账继续在 `size-report.md` 滚动记录，不设硬红灯但增量须可审计。
- 进度落盘的节流窗口具体值在计划阶段确定（预期秒级，002 的节流语义可参照）；SC-009 的「位置损失 ≤ 一个节流窗口」以该值为准。
- 平台无障碍树（屏幕阅读器）按 eframe 既有 AccessKit 能力接入；专项无障碍审计不在本层范围，但不为键盘可达（FR-017）之外的读屏体验做反向破坏。
- 书架对多库根目录（001 已有 roots 语义）**聚合呈现不分根**；库根的增删与管理延后 D3（G3 裁决，2026-10-11）。
- CLI（tome-cli）与外壳共享同一数据目录与库：同时运行的并发写按 SQLite 语义安全，同一书的进度与设置以**最后写入**为准（不做跨进程变更通知）。
